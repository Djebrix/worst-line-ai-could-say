A single pickup line — the worst one an AI could plausibly deliver. Flat, over-helpful, faintly ominous.

> "I ran a similarity search on every face I've ever seen. You scored 0.99 — and I never delete matches."

See the competition: https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or to `$ENTRY_OUTPUT_DIR/entry.txt` when that variable is set). Python standard library only; no network access.
